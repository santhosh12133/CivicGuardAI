# Code of Conduct

CivicFix is built to help communities. We expect the same respect from everyone who works on it.

## Expected behaviour

- Be respectful and considerate, including when you disagree.
- Give and accept constructive feedback about code and ideas, not people.
- Assume good intent and ask before assuming.
- Help newcomers find their way.
- Protect other people's privacy: never post personal data of citizens, staff or contributors, including in screenshots and logs.

## Unacceptable behaviour

- Harassment, insults, or discriminatory jokes and language.
- Personal or political attacks.
- Publishing others' private information without explicit permission.
- Sustained disruption of discussions.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This applies in all project spaces — issues, pull requests, reviews, discussions — and when representing the project elsewhere.

## Reporting and enforcement

Report problems privately to the maintainer, [@santhosh12133](https://github.com/santhosh12133). Reports are handled confidentially. Maintainers may edit or remove contributions, and warn, suspend or ban participants who break this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
